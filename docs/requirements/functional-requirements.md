# Requisitos funcionales

## Propósito

Este documento organizará los requisitos funcionales del prototipo. El equipo deberá
confirmar cada necesidad antes de convertirla en una especificación definitiva.

## Apartados pendientes

- Participantes registrados.
- Avatares asociados a participantes.
- Roles y permisos.
- Guías turísticos.
- Recorridos individuales y grupales.
- Zonas geográficas del sitio arqueológico.
- Operaciones de alta, baja, modificación y consulta.
- Estadísticas de recorridos y reputación.

## Criterio de redacción

Cada requisito deberá incorporar, cuando sea aprobada su redacción, un identificador,
una descripción verificable y su prioridad.
