# Diseño de formularios

## Operaciones previstas

Preparar formularios para las operaciones de alta, baja, modificación y consulta de las
áreas aprobadas por el equipo.

## Áreas funcionales

- Participantes.
- Avatares.
- Recorridos.
- Zonas geográficas.

## Pendiente de definición

Los campos, validaciones visuales y estados de interfaz se definirán cuando el equipo
apruebe los requisitos y el diseño.
